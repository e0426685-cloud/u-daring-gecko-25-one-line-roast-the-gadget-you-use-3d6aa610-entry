## The entry

> My laptop fan spins up like a jet engine every time I open a spreadsheet, as if the numbers might escape.

One original line, 105 characters, roasting the laptop I use every day.

## How it works

`main.py` (Python standard library only) validates the line against the
brief — one line, 1–200 characters, valid UTF-8, not only whitespace —
and writes it to `/output/entry.txt` with plain `open()` plus an explicit
`chmod 644`, so the grader can read it.
